# CRW-1063 — sed write destinations after the first operand, read as getopt_long reads them

Source: Linear CRW-1063, found by the independent verifier of CRW-941 on dev 09e5c5bcc (/state/crw/mgmt/activation-readiness-shell-reader-20261009.md, section 5-1). The oracle is GNU sed 4.9 itself, run directly, and the CXC v0.2.40 memory write gate (3c1459ac, shell-write-destinations.ts). The Go files are internal/pabcd/shellir/gnuopts.go (ParseSedArgs, with SedArgs.PosixScript and PosixTail for the POSIXLY_CORRECT reading), internal/pabcd/shellir/carriers.go (sedInline), internal/pabcd/hook/shellwrite_sed.go and internal/pabcd/hook/shellwrite_ir.go. The reproductions are rows CRW-1063-01 to 38 in internal/pabcd/hook/testdata/shellir/rows/46-crw-1063.txt, indexed in reproductions.tsv. The report predates the CRW-941 commits (f2b3d34a0 to 93b9b8448) that reached dev after 09e5c5bcc, and on dev 7839042f6 no red row was found.

- GNU sed reads -e, --expression, -s, -i and --in-place after the first operand, because getopt permutes the arguments. A w, W or s///w file written after that operand is a write (sed p x.txt -e 'w MEMORY/a'), and so is a backup place of a later -i (sed p x.txt -i -e 'w MEMORY/a', sed p x.txt -i'MEMORY/*'). With POSIXLY_CORRECT set, getopt stops at the first operand: that operand is the script and the later words are files. port: fixed (CRW-941; rows CRW-1063-01 to 20 and 24 to 38 pin the forms).
- A differential check of this change ran 36,783 generated sed argument orders (scripts, options and operands in all orders up to three words, and 6,000 random four-word orders) through GNU sed 4.9 in a temporary memory root and through the memory write gate. Where sed wrote into the root, the gate asked in every order, with POSIXLY_CORRECT unset (0 gaps) and with it set (0 gaps). The gate also asks in 17,879 and 17,284 orders in which sed wrote nothing: the reader judges both readings, so these are over-approximations, and they stay as they are. port: fixed (CRW-941); the check is a temporary probe and is not committed.
- Two -i options in one command: GNU sed keeps the last suffix, so sed p x.txt -i'MEMORY/*' -i moves no backup into memory. The reader agrees; row CRW-1063-27 is that control. port: fixed (reader agrees).
