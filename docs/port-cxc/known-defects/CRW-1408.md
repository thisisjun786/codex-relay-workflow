# CRW-1408 — the follow-ups of CRW-1404: a planned region declared from its fields, the Exclusive check of the region spellings test

Source: CRW's own design (the decided defaults of CRW-1408, from the Argon V5 review of the CRW-1404 lane, head c14662af: two P3, confirmed), not the CXC oracle: CXC v0.2.40 (commit 3c1459ac) has no flow run. The Go side is `internal/flow/cli/schedrelay.go` (`declareRegions`) and `internal/flow/ops/lane_design.go` (`RegionFormOf`, `RegionForm.Text`, `RegionOf`); the tests are in `internal/flow/cli/region_forms_test.go`; the reference is `docs/flow/script.md` ("The lane of a node").

- Item 1: `declareRegions` turned each planned `compile.Region` into its text (`String`) and read it again with `ops.RegionOf`, which takes what follows the last `#` as a symbol, and it read the plan's own region texts in the release request the same way. A planned file or tree whose path holds `#` (`compile.cleanRegion` allows it), such as `pkg/a#b.go` or `gen#1/`, was declared to the relay as a symbol (`pkg/a` `b.go`, `gen` `1/`), with the plan's change and exclusive flag; port: fixed (a planned region's normal form is taken from its fields, `ops.RegionFormOf`: the path cleaned as `compile.cleanRegion` and `DeclareRegions` clean it, the kind, a file when none is named, and the key; the plan's own text of a region, as the manifest writes it (`RegionForm.Text`, which is `compile.Region.String` of the cleaned region), trimmed, is that planned region and is not parsed; only a DESIGN `edit_regions` text that is not a planned region's text is read with `RegionOf`. The relay's store form and the manifest are unchanged. `TestReleaseDeclaresAPlannedPathWithAHashAsThePlanStatesIt` (a planned file and tree with `#` in the path, a planned symbol with `#` in its path, a DESIGN symbol beside them); red first).
- Named limit: a DESIGN `edit_regions` entry whose text is exactly a planned region's text (trimmed) is that planned region, even where the DESIGN meant the symbol its `#` would name; the lane already admits such an entry once with the plan's text (`AdmissionRegions`, `crw:lib/lane` `admissionRegions`), so the two never reached the relay as two regions; port: kept (the plan's region is the one the scheduler's gate reads).
