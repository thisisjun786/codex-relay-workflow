# CRW-451 — the shared Node text helpers (internal/jsnode): copies merged, two number edges and two lone-surrogate edges decided

Source: the copies of Node's `Buffer.toString("utf8")`, `String.prototype.toLowerCase`, `JSON.stringify` and `Number.prototype.toString` that the port kept per package (`internal/pabcd/host`, `projectcfg`, `source`, `interview`, `metric`, `gate`, `goalplan`, `attest`, `state`, `evidence`, `internal/relay/job`, `internal/harness`, `internal/role`, `internal/role/spawn`, `internal/recall`, `internal/provider`, `internal/contracttest`, `internal/runtime/doctor`, `internal/dev/cxcfuzz`), now one implementation in `internal/jsnode`. The string and number rules are the ones the oracle's runtime gives at v0.2.40 (commit 3c1459ac): the WHATWG UTF-8 decoder, ECMAScript `QuoteJSONString`, `Number::toString` and `toLowerCase` with Final_Sigma. A cross-copy equivalence run before the copies were deleted found the nine UTF-8 decoders and the four `JSON.stringify` bodies identical, the string quoters identical for well-formed text, and the number formatters identical for every finite value, so the merge changes nothing else.

- The gate's number formatter had no NaN branch, so `json.Marshal` failed and a NaN spelled as the empty string where JavaScript's `String(NaN)` is "NaN"; it is the shared `NumberString` now. No receipt can carry a NaN exit code (JSON has none), so the text is reachable only through a caller that computes one. port: fixed.
- The manifest-target message spelled a number literal past the double range with Go's `strconv` verb as "+Inf" and "-Inf", where JavaScript's `String()` of the infinity the literal parses to is "Infinity" and "-Infinity" (the message names the offending `hooks` or hook file value); it is the shared `NumberString` now. port: fixed.
- `recall.Lower` lowered a byte outside UTF-8, or the three WTF-8 bytes of a lone surrogate, as U+FFFD runes, where `attest` and `spawn` kept the original bytes as the JS reading leaves a lone surrogate; the shared `Lower` is the keeping one, so recall now keeps such bytes in a string it lowers (no recall test and no recorded corpus case pins the old replacement). The one recall input that held raw bytes, the query words of `crw recall chat search` and `memory search` (Node decodes `process.argv` as UTF-8 before the code runs), is decoded with `DecodeUTF8` at the CLI (`recallCLIQuery`), so a query byte outside UTF-8 is one U+FFFD and still finds the decoded text it stands for, as it did when `Lower` itself replaced it. port: fixed.
- The string quoters of `harness`, `contracttest`, `evidence`, `interview/ledger`, `provider`, `metric`, `goalplan` and `pabcd/cli` (divergence) wrote the three WTF-8 bytes of a lone surrogate as three U+FFFD, where `projectcfg` wrote the escape `\udXXX` that `JSON.stringify` writes for a lone surrogate; the shared `JSString` writes the escape, and a byte that is not UTF-8 stays U+FFFD for all of them. Their inputs are Node-decoded text or Go-decoded JSON, which hold no WTF-8 bytes, and no test or recorded corpus case pins the old three replacements. `relay/job`'s `quote` is not among them: it decodes a string that is not valid UTF-8 (the three WTF-8 bytes of a lone surrogate are not) with `DecodeUTF8` before `JSString`, as Node decodes its arguments, so those bytes were and still are three U+FFFD there, and a lone surrogate reaches its ledger only as a caller's raw JSON token. port: fixed.
- Kept as local code: `recall`'s `hookContextQuote` (UTF-16 units, and it escapes `<`, `>` and `&`), `recallHookQuote` and the relay's `quoteJSON` (Python `json.dumps` spellings through `pyjson`), `state.jsNumber` (the JSON-value normalisation that turns NaN and the infinities into null, which is not `NumberString`), `interview.jsString` (a constructor of the freeze value type, not a quoter), the `gate` and `goalplan` `jsNumber` parsers, and the projectcfg object-order walker in `stringify` (it keeps `JSON.stringify`'s member order for an ordered object; only its string and number leaves are shared). port: kept (different meaning, not a copy).
