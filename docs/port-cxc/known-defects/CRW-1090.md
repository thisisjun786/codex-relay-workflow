# CRW-1090 — the R-11 transcript guards read Codex records, and a compaction ends the old generation

Source: `plugins/codexclaw/components/pabcd-state/src/transcript.ts` (`hasStageMarkerForPhase` :57-64, `isContextPressureTail` :66-74) and its callers `hook.ts:803-816` (the R-11 guards of `handleUserPromptSubmit`) and `hook.ts:1805-1873` (`handleStop`) at CXC v0.2.40 (commit 3c1459ac). The Go side is `internal/pabcd/host/transcript_generation.go` (`ReadTranscriptGeneration`), called from `internal/pabcd/hook/prompt_trigger.go` and `internal/pabcd/hook/stop.go`. Found by the 10-10 isolated real-use trial (S4-F1, P1) and the 10-10 CXC improvement review (A1-02).

- After a compaction the next prompt did not get the phase directive back. PostCompact resets `lastInjectedPhase` to null, but the Codex rollout is append-only and its `compacted` record keeps the pre-compaction history (`replacement_history`, `guardian_history`), so the stage header `[crw — P: PLAN]` the compaction removed from the model's context was still inside the 64 KiB tail; `hasStageMarkerForPhase` found it, the handler wrote `lastInjectedPhase` back to the phase and answered nothing. Whether it happened depended on how far the compacted record reached into the tail (trial sessions s1-r3 and s1-r5 lost the directive, s1-r6 got it; the reproduction is synthetic, built in `internal/pabcd/hook/prompt_submit_legs_crw1090_test.go` with the trial's record shapes and sizes and none of its content); port: fixed (the tail is read as whole JSONL records, the cut first line of a window that does not start the file is dropped, and only the records after the last compaction the tail shows count: the `compacted` record, or the `event_msg` item_completed of item type ContextCompaction that follows it, or the older `context_compacted` event; the compacted record's own histories are never read. A cursor PostCompact reset is never set again from the tail, so the prompt after a compaction injects the full directive (mode 2). Pinned by `TestCRW1090S4CompactionReinjectsThePlanDirective`, which drives the wired leg with a synthetic state and rollout of that shape, and `TestCRW1090SameGenerationInjectionDedups`).
