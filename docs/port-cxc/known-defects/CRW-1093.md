# CRW-1093 — memory authorization from affirmative user requests

Source: CXC v0.2.40 `pabcd-state/src/memory-write-gate.ts:78-105`, ported in `internal/pabcd/hook/detect.go`.

- The whole-prompt detector armed a one-write marker from negated or quoted examples; port: fixed. Only affirmative user sentences authorize memory. Quoted spans, backticks, Markdown fences, blockquotes and embedded task packets are excluded. Memory-specific English and Korean negatives override affirmative idioms in the same sentence. Lists, don't-forget / 잊지 마 and requests referring to following quoted content remain affirmative. Other prompt detectors and `prompt_submit.go` are unchanged.
- `TestCRW1093PromptToProtectedWrite` runs prompt submission followed by a protected Write with PABCD on and off, checks the marker, and denies a second write. `TestCRW1093ConcurrentAndNextTurn` permits exactly one of eight concurrent writes and denies a later turn. The CLI grant and cwd/session/turn binding are unchanged. Recorded detector expectations for negation, quotes and Korean sentence endings intentionally differ from the oracle.
