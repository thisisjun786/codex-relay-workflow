# CRW-1109 — the orchestrate command grammar sweep (chat and CLI)

Source: CXC v0.2.40 (commit 3c1459ac) `plugins/codexclaw/components/pabcd-state/src/orchestrate-grammar.ts`
(:31-45, :93-96, :112-127), `hook.ts` (:860-896), `orchestrate-cli.ts` (:143-145, :169-175, :226-270) and
`goalplan.ts` (:580, :667-669, :875-913, :988-993). The port is `internal/pabcd/fsm/grammar.go`
(`ParseOrchestrateCommand`, `OrchestrateCommand.FormError`), `internal/pabcd/hook/prompt_orchestrate.go`
(the refusals before the first gate), `internal/pabcd/cli/orchestrate_args.go` (`scanOrchestrateCliFlags`,
`ParseOrchestrateCliArgs`) and `internal/pabcd/goalplan/plan.go` and `read.go` (`validSchemaVersion`,
`firstInvalidField`). Each item was reproduced on dev (6a5851f4f) before it was changed; the red output is in
`/state/crw/crw-lane-orchestrate-atomicity/evidence/CRW-1109/`. Every item is a line of
[known-defects.md](../known-defects.md) that now reads port: fixed by CRW-1109; the lines carry the details.

- `:135` — the chat `constructor` verb: no command any more (`TestConstructorIsNoVerb`).
- `:137` — a CR, U+2028 or U+2029 inside a command's `--attest` text: refused with a form error instead of
  being read as chat (`TestSeparatorInACommandIsAFormError`, `TestPromptOrchestrateSeparatorInACommandIsRefused`).
- `:138` — an explicitly malformed chat `--attest`: refused before the free transition; a left-out attest is
  still valid (`TestPromptOrchestrateMalformedAttestIsRefused`). The refusal says the command "was not applied": the
  prompt entry has stamped the session's turn already, so it no longer claims that nothing was written.
- `:234` — a schemaVersion that is not a whole number from 1: refused with its own diagnostic, bytes kept,
  absence still version 1 (`TestSchemaVersionMustBeAWholeNumberFromOne`). The goalplan write lock refuses a writer for
  such a plan (it is there, only not readable), so a gated edge never publishes past the work-phase gate as it would
  for an absent plan (`TestOrchestrateGatedEdgeRefusesAPlanWithAnInvalidSchemaVersion`).
- `:346` — the shape diagnostic names the slug, criterion id and steering-entry fields instead of
  `(unknown)` or a defaulted host (`TestShapeDiagnosticNamesTheField`).
- `:529` — the CLI's `constructor` and `__proto__`: unknown verbs (`TestOrchestrateArgsDocumentedVerbsOnly`).
- `:530` — help after the option values: `--session help` is a session (`TestOrchestrateArgsHelpAfterTheValues`).
- `:531` — strict options: unknown, stray, missing and swallowed values refused (`--attest` included: `reset --attest --cwd=<dir>`
  is a parse error, so a reset never runs against the input workspace; a missing `--attest` or `--attest-file` value is a parse
  error for every verb, so `reset --attest` refuses and leaves the session as it was, `TestOrchestrateResetRefusesAMissingAttestValue`;
  the short help option `-h` is no value either, `reset --attest -h` is refused, `TestOrchestrateResetRefusesTheShortHelpAsAnAttestValue`),
  `--flag=value` read; the
  skill calls of `plugins/crw/skills` parse unchanged (`TestOrchestrateArgsStrictOptions`).
- `:532` — one selection rule for the diagnostic and the command, and a conflicting `--session` or `--cwd`
  repeat refused before any write (`TestOrchestrateArgsConflictingRepeats`).

Recorded cases that move with these items are tagged intentionally changed in their replays, the recordings
unchanged: seventeen parser cases and one attest-file case of `internal/pabcd/cli/testdata/orchestrate_args/oracle.json`

`internal/pabcd/fsm/testdata/oracle-grammar.json` (`TestGrammarMatchesTheRecordedOracle`), six version cases
of `internal/pabcd/goalplan/testdata/oracle-plan.json` (`oraclePlanRefusedVersions`) and three diagnostic
cases of `internal/pabcd/goalplan/testdata/oracle-read-lock.json`. No `contract/fixtures/cxc` fixture uses any
of the refused forms, so no corpus claim changes. `fsm.VerbConstructor` and `cli.VerbProto` stay as values for
a Go caller that hands them over directly; neither parser produces them. The status-diagnostic items `:628` to
`:631` belong to CRW-200 and are not part of this sweep.

Agent flow: a command that used to pass silently - a typo'd flag, a stray word, a malformed attest, a command
line broken by a separator - is refused with a sentence that names the problem, and the agent corrects the call.
