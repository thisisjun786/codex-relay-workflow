# CRW-145 — the goal-idle block leads with the arming command, and offers it where it cannot run

Source: CXC v0.2.40 (commit 3c1459ac) `plugins/codexclaw/components/pabcd-state/src/hook.ts` `buildGoalIdleBlock` (:1694-1738; the oracle's `startNext` line, the "or close the goal honestly" line and the no-slug `loop init` branch). The Go side is `internal/pabcd/hook/stop.go` (`stopGoalIdleBlock`) and the predicate it reads is `internal/pabcd/source/session/gate.go` (`CheckBound`), the one `orchestrate P` applies to a goalplan-bound session (`internal/pabcd/cli/orchestrate_transition.go`, #133). Found by CRW-29 (the completion boundary of a project parent): the block instructed `orchestrate P` in a workspace where it is refused.

- The block opens with "Either start the next work-phase now: `orchestrate P`" and names the honest exits (`update_goal` complete or blocked) second, and it offers the command in a workspace with no resolvable source identity, where `orchestrate P` of a goalplan-bound session is refused ("this workspace has no resolvable git source identity ...") (hook.ts:1694-1738); port: fixed (the honest exits come first: "Close the goal honestly: `update_goal` status "complete" (...) or status "blocked" for an external blocker.", then "Or start the next work-phase now: `crw pabcd orchestrate P --session <id>`" where the command can run. When `session.CheckBound(cwd, sessionId)` fails the command line is replaced by the reason, "The next work-phase cannot be armed from this workspace: it has no resolvable git source identity, and a goalplan-bound cycle cannot be closed without one (C -> D needs a test receipt bound to a commit), so entering P is refused. To make arming possible, bind a git source tree: `crw relay session source <absolute-path> --json`.", and the LOOP-UNIT-CHAIN-01 line ends its parenthesis at "append it to the goalplan" instead of "then orchestrate P". The predicate is the source identity and not the absence of `.git`, as `CheckBound` documents: a non-git working directory whose session is bound to a git source worktree can run the command and keeps the option. The block is still a block: the decision, the counter (counted at IDLE, three consecutive per phase, 24 per user turn), the work-phase lines, the empty-plan line and every other branch are the oracle's. The identity is investigated (git status, the hashing of the dirty files) before the session lock is taken, never under it, so a slow investigation does not make another writer of the session give up its lock; it is read only for a Stop that reaches the block (after the role release, and not once the turn's total cap was announced), the lock then re-judges the binding, the goal and the turn as before, and the block uses the answer already in hand. The investigation has a 5 s budget inside the 15 s Stop wiring limit: one that does not finish in it is no evidence that arming is impossible, so the oracle's arming command is offered.
