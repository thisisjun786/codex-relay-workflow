# CRW-1078 — the unsupported-ocx-catalog deviation is recorded

CRW-1078 is a record-only issue: it adds the missing defect record of the live-catalog change CRW-890 made, and changes no
code. The record is [CRW-890.md](CRW-890.md), named after the issue whose change it describes, as the issue's end condition 1
requires; the row in [known-defects.md](../known-defects.md), "Found by the oracle review of the live model catalog
(CRW-1078)", is the end condition 2. The oracle behaviour (`live-catalog.ts:108-113`), the port's (`internal/role/livecatalog.go`,
`catalog.go`), the before and after states and messages, and the two pinning tests
(`TestLiveCatalogTellsUnsupportedFromAFailure`, `TestRunOcxModelsClassifiesTheCommandRejection`) are there.

- An OCX that refuses the live-catalog command is its own catalog state, `unsupported-ocx-catalog`, where the oracle reports an
  ordinary discovery failure; port: fixed (decided by CRW-890, recorded in [CRW-890.md](CRW-890.md)).
