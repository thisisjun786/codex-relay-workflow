# CRW-1411 — the follow-up of CRW-1408: a planned region matched by its normal form, a planned file and symbol of one text, and the kind default

Source: CRW's own design (the decided defaults of CRW-1411, a follow-up of CRW-1408), not the CXC oracle: CXC v0.2.40 (commit 3c1459ac) has no flow run. The Go side is `internal/flow/cli/schedrelay.go` (`declareRegions`), `internal/flow/ops/lane_design.go` (`RegionReadings`, `RegionFormOf`) and `internal/flow/ops/seams.go` (`PlanNode`); the tests are in `internal/flow/cli/region_forms_test.go`; the reference is `docs/flow/script/project-lane.md` ("The lane of a node").

- Item 1: `declareRegions` looked a request text up by its text, so a text that spelled a planned file or tree unclean (`./pkg/a#b.go`, `gen#1//`, `pkg/a#b//c.go`), or the handoff's own spelling from the Milestone's `rg.String()`, did not match it. The `#` in the path read as a symbol (`pkg/a` `b.go`, `gen` `1//`, `pkg/a` `b//c.go`), and the planned file or tree was not declared with its change and exclusive flag; port: fixed (a request text names each planned region that one of its readings, `ops.RegionReadings`, equals, and a planned region is matched by its normal form, `ops.RegionFormOf`; red first: `TestReleaseDeclaresAPlannedHashPathInAnUncleanSpelling` and `TestReleaseDeclaresTheMilestoneTextsOfAPlannedHashPath`, both failing on the base code).
- Item 2: a planned file and a planned symbol with one text (the file `pkg/a#b.go` and the symbol `b.go` of `pkg/a`) shared one entry of the text index, so one of the two was not declared; port: fixed (a text declares every planned region it names, each with its own change and exclusive flag; red first: `TestReleaseDeclaresAPlannedFileAndSymbolOfOneText`, failing on the base code with one of the two regions declared).
- Item 3: the kind default in `ops.RegionFormOf` (a region with no kind is a file; `lane_design.go:461-463` at base e4a268e) was already present in commit `1b83e40f8` (CRW-1408), and no test pinned it, so a test of the default alone could not fail on the base code. The record offered for the red-first criterion is `TestReleaseDeclaresTheMilestoneTextsOfAPlannedHashPath`, whose planned region has an empty kind: it fails on the base code and passes at the head. The mutation runs, each restored and confirmed by `cmp` against a copy taken just before the mutation: with the default removed, `TestRegionFormOfReadsNoKindAsAFile` and `TestReleaseDeclaresTheMilestoneTextsOfAPlannedHashPath` fail at the base code and at the head. Decision A closes OQ1: the recorded failures with the default removed satisfy the red-first criterion; port: fixed (test added, default unchanged).
- Supersedes CRW-1408.md, item beginning "Named limit": now port: kept (the limit widens from a text equal to a planned text to a text one of whose readings is a planned region; such a DESIGN text declares each planned region it names, with the plan's change and exclusive flag).
