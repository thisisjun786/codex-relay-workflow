# CRW-1040 — the night batch: selection and the morning report (part 1040a)

Source: CRW's own design, not the CXC oracle (CXC v0.2.40, commit 3c1459ac, has no batch selector and no morning report; the pointer is the port). The Go side is `internal/manage/batch.go` (`crw manage batch plan`), `internal/manage/batch_report.go` (`crw manage batch report`) and `internal/skill/issue_ready_export.go` (`CheckIssueReady`, the exported release gate); the report form is `plugins/crw/skills/crw-status/references/night-batch-report.md`.

- The issue asks for a label-started batch that thaws a release freeze for the labelled issues only and then releases them (CRW-1040 c1, c2); the port does not build freeze or grant tables. 1040a is the pure half (a plan from caller-supplied Linear issue JSON, a report from a run digest), 1040b becomes a v2 night-batch flow run that releases only inside the run, and no global rule defers releases without a grant (coordinator ruling, 2026-10-11); port: kept (deviation: c2 "an issue outside the label is not released during a freeze" is not satisfied by this part. The plan only selects, and the report lists any digest item outside the selected list under Jun's decision. What a real acceptance of c2 must observe, the freeze scope, the runs and parents alive at the same time and every release in that scope, is open in the 1040b/1040c work).
- The selector checks the state (Backlog, every state value the input carries) and the label itself and judges readiness through one exported helper of `internal/skill`, `CheckIssueReady`, which `crw skill issue-ready check` also uses; the helper takes no exception, so a batch never releases an issue on a recorded bypass; port: kept (CRW's own design).
- A quota provider that cannot be observed is recorded in the digest as not observed and shown so in the report (`관측 안 됨`), never assumed to have room; how an execution decision is bound to a budget or provider hold while quota is unobserved is open in 1040b; port: pending.
- The retry of a failed node is not a rule of this part: the night run uses the v2 tier policy (SP-TIER-1) unchanged and carries what the deadline or budget cut off into the report; port: kept (the issue's open decision "one retry, Haiku to Sonnet" is not adopted).
