# CRW-1016 — the hook observation record's trailing data and observedAt spelling after CRW-616

Source: the post-merge evaluation of CRW-616 (P1, PR #603), read statically against the port's base 7d23cd46f. The oracle is CXC v0.2.40 (commit 3c1459ac): `plugins/codexclaw/scripts/hook-observation.mjs` (`readHookObservations` :86-129, whose record is read with `JSON.parse` and whose `observedAt` is read with `Date.parse`) and the execution check in `plugins/codexclaw/components/cxc-ops/src/doctor.ts` (`runHookExecutionCheck` :448-467). The Go files are internal/harness/observation_read.go (`ReadHookObservations`, `observationRecord`, `observationPayload`), internal/harness/payload.go (`decode`) and internal/runtime/doctor/harness_hooks.go. The oracle was not run for this record; the cases are the reader's own tests in internal/harness/observation_read_test.go.

- A record with data after its JSON object, for example an appended `{}` or junk, under 8192 bytes, is rejected as a whole by the oracle's `JSON.parse`: no observation, one ignored, and the execution check WARNs. The port kept the first object and discarded the whole-document result of `decode`, so the record was read as an observation. The manifest payload read by `observationPayload` (the digest every record must match) had the same discard and is refused the same way; port: fixed (both reads refuse a document with data after its object; pinned by `TestReadHookObservationsRefusesWhatItCannotTrust` with the `trailing object` and `trailing junk` cases, and by `TestObservationPayloadRefusesAManifestWithTrailingData`). The oracle's own corpus holds only a lone `{` as a corrupt record (`internal/runtime/doctor/testdata/harness/hooks/oracle.json`), so no recorded case covers the trailing-data shape.
- The oracle adopts a record whose `observedAt` is any spelling `Date.parse` reads (`"2026-01-01 00:00:00 UTC"`, `"Jan 1 2026"`, `"2026"`) as fresh when the rest of the record holds. The port reads `observedAt` as RFC 3339 only, the writer's spelling and any other RFC 3339 time, so such a record is not fresh and counts as ignored; port: intentionally-changed (decision D1 of CRW-1016: widening to a Date.parse grammar would reproduce an engine's locale-free reading of times the writers never emit, and the writers emit only RFC 3339 `.000Z` times; the narrowing is recorded here and not as `kept`. Pinned by the `observedAt in another Date.parse spelling` case of `TestReadHookObservationsRefusesWhatItCannotTrust`). The difference shows only in the doctor's hook-execution diagnostic, which reads the store and changes no state.
