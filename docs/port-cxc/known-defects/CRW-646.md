# CRW-646 — the loop CLI's read verbs (init, show, validate, ready)

Source: CXC v0.2.40 (commit 3c1459ac) `plugins/codexclaw/components/pabcd-state/src/goalplan-cli.ts`,
`runReady` (:461-525) and the init/show/validate/ready branches of `runGoalplanCli` (:751-865), plus the
`loop` dispatch in `src/cli.ts` (:169-180). Ported into `internal/pabcd/cli/loop.go` (the command library),
`internal/harness/pabcd_cli.go` (the `loop` row) and `internal/harness/pabcd.go` (the verb table).

- The oracle guards a non-canonical `--session` id for `ready` alone (:802-810), so `show --session a/b` and
  `validate --session a/b` address the state file of session `a-b` (state paths sanitize the id) and print
  or judge a plan the caller never named, while `ready` refuses the same input (:821-839;
  `internal/pabcd/cli/loop.go`, the ready guard against the shared ResolveLoopSlug path); port: kept.
- Supersedes docs/port-cxc/known-defects/CRW-646.md, item beginning "The oracle guards a non-canonical":
  now port: fixed (Devin review finding of kind "security", 2026-10-06: the parity revision fixes a security
  finding during the port; the guard now covers every verb that resolves a plan through --session).
- The oracle asks only whether a plan LOADED, so a truncated or structurally invalid
  `<cwd>/.crw/goalplans/<slug>/goalplan.json` reads as absent and `writeGoalplan`'s rename replaces its bytes,
  while a `created` ledger row is appended to the replacement (`goalplan-cli.ts`:764-767); port: fixed
  (data-loss class: the port refuses unless the diagnostic says the file is absent, so a damaged plan stays
  for repair).
- The oracle binds a slug with `readState` + `writeState`, and `readState` answers a fresh IDLE state for a
  session file it cannot decode, so `loop init --session <id>` replaces a damaged session state with a
  default (`goalplan-cli.ts`:795-798 against `state.ts` readStateStrict); port: fixed (data-loss class: the
  port reads the state strictly, under the session lock, and refuses an unreadable file).

No other defect was found in this issue's ranges: the ported units reproduce the oracle's answers through the
corpus replayer (19 fixtures, `contract/notes/cxc/CRW-646.json`) and through the ported TypeScript cases.
