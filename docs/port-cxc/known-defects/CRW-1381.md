# CRW-1381 — the follow-ups of CRW-1366: an answer for each question of a joined ask, a question a later DESIGN no longer raises, the empty origin

Source: CRW's own design (the carried d3 and the P3 items of the final verification of the CRW-1366/CRW-1365 lane, head `bbf54101`, `/state/crw/mgmt/pre-eval/crw1366-7d4302c9.json`), not the CXC oracle: CXC v0.2.40 (commit 3c1459ac) has no flow engine, no explorer routing and no answer path of a run. The Go and script side is `internal/flow/cli/answer.go` (`--answer-for`), `internal/flow/cli/answer_rules.go` (`Judge`, `Claim.Answers`, `unknown_question_digest`, `answer_part_not_recorded`, `single_answer_for_joined_ask`), `internal/flow/cli/runs.go` (`Question.Questions`), `internal/flow/ops/lane_decisions.go` (`orchestratorAnswer`, `carriedQuestions`, `RoutePlan.Carried`, the routes of `crw.exploreRoute` and the answers of `crw.exploreRecord`), `internal/flow/workflows/project-lane.js` (`askOrchestrator`, `auditedDesign`) and `internal/flow/workflows/lib/lane.js` (`explore`); the references are `docs/flow/script.md` and `plugins/crw/skills/crw-canon/references/flow.md` ("crw flow answer").

- Supersedes CRW-1366.md, item beginning "Named limit: the orchestrator answers an ask as a whole": now port: fixed (`crw flow answer --answer-for DIGEST=TEXT`, once for each question, gives each question an ask joins its own part of the recorded answer: `Judge` takes a part only for a digest the ask's evidence names (`unknown_question_digest` otherwise) and only as text of the record's answer (`answer_part_not_recorded`, so the record stays the one source of the answer), both input errors that append nothing; the `decision_applied` row keeps the parts by digest in `decision.answers`, and `orchestratorAnswer` gives a question its part, else the whole text or option, as before. Red first: `TestEachQuestionOfAJoinedAskGetsItsOwnAnswer` and `TestAnswerForGivesEachQuestionOfAJoinedAskItsPart`).
