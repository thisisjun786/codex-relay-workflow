# CRW-1085 — readable diagnostic commands and bounded Python test discovery

Source: CRW's shared shell reader (`internal/pabcd/shellir`), destination reader and the isolated command trials. CXC v0.2.40 has no equivalent reader. This supersedes the blanket module refusal recorded in CRW-894 and the opaque carried-shell-file memory classification in CRW-1028.

- Version/help options with no program operand and shell noexec syntax checks were refused as programs; port: fixed. `[` is read like `test`. Shell noexec can be disabled again with +n or +o noexec; that form still reads the executed program.
- Python -m refused ordinary test and JSON commands; port: fixed. The fixed list is unittest, pytest, py_compile and json.tool. Explicit Python file operands are bounded regular files; discovery walks cwd for test*.py and *_test.py (pytest also includes conftest.py), with at most 128 files and 1 MiB total. Unknown directories, unreadable files, FIFO, local import shadows, rewritten import/source files and unordered module execution refuse. The no-directory reading delegates directory-dependent checks to the two directory-aware readings. Unsupported modules/options remain unreadable. json.tool input operands are data, not Python programs.
- Every carried shell file required a memory grant, including an existing harmless sh/bash script; port: fixed. The destination leg reuses the GitHub guard's bounded nonblocking regular-file reader, stale-file tracking and four-level script depth. Outer writes follow into nested scripts. Unreadable or rewritten files retain an unknown destination. Existing corpus rows for readable scripts now record their actual modeled destinations; GitHub/worktree verdicts stay unchanged except the explicitly allowed clean json.tool controls.
- Read-only awk was unknown; port: fixed. A program without >, pipe, system() or getline is read-only. Programs with any such operation remain unknown. This intentionally conservative rule can still refuse strings/comments containing those tokens.
- Tests: TestCRW1085ReadableCommandsAtIngress exercises memory and GitHub ingress; TestCRW1085ModuleBoundsAndSpecialFiles pins discovery limits and FIFO refusal; TestCRW1085NoExecDoesNotHideExecution pins disabled syntax-only mode. The full existing reproduction and shell-family rows cover rewritten/shadowed files. Trial agent launches remain the coordinator's operation; this lane does not contact agents.
- CRW-951's Python computed-destination work is not duplicated. Its workspace Path(variable).write_bytes case needs the predecessor's integrated implementation; it is tracked separately in the private handoff.
