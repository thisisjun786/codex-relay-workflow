# CRW-993 — the restore identity and the case-only alias after CRW-899

Source: CRW-899 pre-merge evaluation pr841-e36c7ac5 (defects d1, d2 and d3). The defects are the port's own. CXC v0.2.40 (commit 3c1459ac) has no sidecar lock and no identity comparison of the config path (source `deactivate.ts:117,122,132,155`). The Go files are `internal/runtime/install/configguard/deactivate.go` (`Deactivate`, `configLockPathsSameTarget`, `configLockPathsPublishGuard`), `activate.go` (`configLockPathsPublishChecked`) and `internal/pabcd/crwdir/atomic.go` (`PublishChecked`).

- The restore compared the manifest's file and parent with the pinned file and directory, but never the live parent of the pinned pathname. A directory moved away after the pin, and replaced under the old name with hard links to the config file and its sidecar, was accepted: the restore published into the replacement and reported the key restored while the file the manifest names kept it (CRW-899 evaluation d1); port: fixed (the live parent of the pinned pathname must still be the captured directory, checked before the comparison and again immediately before the rename by `crwdir.PublishChecked`, so a refusal publishes nothing. Pinned by `TestConfigLockRestoreIdentityRefusesAHardLinkedReplacementDirectory`, with the controls `TestConfigLockRestoreIdentityRestoresAnOrdinaryFile` and `TestConfigLockRestoreIdentityRestoresAMovedDirectoryWithIntactIdentity`).
- A case-only alias of the locked entry is refused when its parent directory has no read permission, although the entry can still be proven by a lookup through a held descriptor (CRW-899 evaluation d2); port: pending. The lookup cannot tell a case-variant hard link on a case-sensitive filesystem from a case-only alias on a case-folding one without a directory listing or a probe, and the predecessor's hard-link refusal (`TestConfigLockPathsRefusesACaseVariantHardLink`, and the E2 rule) needs that difference. The decision is open and is not made in this change.
- CRW-899.md marked the refusal of a valid case alias under an unreadable parent as fixed (evaluation d3); port: kept. The record was edited in place, because it exists only on this branch, and the status follows the current code until the d2 decision.
