# CRW-1075 — a payload nested past 10,000 levels is read, not refused, by the PreToolUse gates

Source: `plugins/codexclaw/components/pabcd-state/src/goal-gate.ts` (`JSON.parse` at :81, :113, :136, :201),
`automation-ownership-gate.ts` (:71) and `cli.ts` (:415-426, the subagent stamp and the payload `cwd`) at CXC v0.2.40,
commit 3c1459ac; the Go port at `internal/pabcd/hook/goalgate.go` (`deepPayload` :44, `deepObject` :50),
`internal/pabcd/hook/automation_gate.go` (:180), `internal/harness/payload.go` (`deepObject` :64,
`IsSubagentHookPayload` :119), `internal/harness/hook.go` (`hookCwd` :36) and `internal/pyjson/loads.go` (`deep`).
Found by the oracle review of 2026-10-10 (finding U04-01).

- The port read a gate's payload with `encoding/json`, which refuses a container nested past 10,000 levels, where V8's
  `JSON.parse` reads any depth. A valid payload whose unread `tool_input` field nested 10,001 levels was then "no payload":
  the budget guard, the unreadable-database guard and the unreadable-state guard answered silence and the automation guard
  denied, each the opposite of the oracle (`goal-gate.ts:81,113,136,201`, `automation-ownership-gate.ts:71`); port: fixed
  (the oracle's behaviour, so no deviation remains: the gates and the entry (`IsSubagentHookPayload`, `hookCwd`) read the
  payload with the Deep reading of `internal/pyjson`, which is what `JSON.parse` does at any depth. The reading keeps its
  containers on the heap, not in calls, and the error walk does too, so a document of a few million levels needs no
  goroutine stack, and a document the input bound admits whose value cannot close what it opens is refused before
  anything is allocated for it; that check reads the value only, so the text a `Trailing` option leaves unread is not
  judged. A Go stack overflow is a fatal error no `recover` answers, which `encoding/json`'s depth limit had
  prevented. Only the escapes JSON has are read, so `"vi\x0065w"` is as broken here as for `JSON.parse`.)

  Pinned by `TestGateVerdictsDoNotDependOnTheDepthOfAFieldTheyNeverRead` (the four verdicts at 9,997, 10,001 and 400,000
  levels), `TestGateDepthDoesNotChangeHowBrokenJSONIsHandled`, `TestGateEntryReadsTheSubagentStampAndCwdAtAnyDepth` and
  `TestGateBoundsNestingByTheInputItReads` (a child process with a 32 MiB stack limit reads 1,900,000 levels and refuses
  3,000,000 unclosed ones, also padded with invalid UTF-8 to the input bound) in `internal/pabcd/hook/gate_depth_test.go`,
  and by `TestLoads_deep_reading_agrees_with_the_recursive_one`,
  `TestLoads_deep_reading_needs_no_stack_for_the_nesting_of_its_document` and
  `TestLoads_deep_reading_past_max_depth_does_not_read_the_trailing_text` in `internal/pyjson/loads_test.go`.
