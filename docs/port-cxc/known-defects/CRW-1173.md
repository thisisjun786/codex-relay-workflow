# CRW-1173 — the -요 verb endings 끝내요, 끝나요 and 바꿔요 did not end a -고 chain

Source: follows CRW-1166 (`CRW-1166.md`), whose loop-arm scope classifier has no CXC counterpart (the oracle gave every un-negated loop request the implementation recipe, CXC v0.2.40 commit 3c1459ac). The Go file is `internal/pabcd/hook/detect.go` (`finiteKorean`, `chainCausative`, `hangulConnective`); the cases are in `internal/pabcd/hook/prompt_loop_scope_crw1084_test.go` (`TestClassifyLoopArmScope`, the CRW-1173 rows). Every row that existed before keeps its result.

- A -요 verb ending outside the list of syllables before 요 did not end a -고 chain, so a causative after it was read as governing the implement verb (port: fixed): "crw-loop 돌려서 현재 세션에서 자식에게 확인하고 구현하고 끝내요 수정하도록 해", and the same with 끝나요 and 바꿔요, got the pointer although the chain ends at the finite verb and the implement verb is this session's own. `finiteKorean` now reads these three verbs by their whole stem (끝내요, 끝나요, 바꿔요). A bare syllable rule was refused, because 내, 나 and 꿔 end noun words too (안내요, 실내요, 바나나요): those keep the causative and are pinned by the CRW-1173 rows (안내요, 실내요, 바나나요, 가요, 대중가요 keep the pointer).
- A bare 그리고 and a sequence marker (그다음, 그 뒤, 그리고 나서, 다음에) do not end a -고 chain (port: kept, a decision, not a defect). In "구현하고 그리고 수정하도록 해" and "구현하고 그다음 수정하도록 해" the causative governs the chain's later verb too, so a boundary there would turn a delegated request into the session's own work. An ambiguous structure keeps the pointer, so these pass through the chain as connectives. Pinned by the CRW-1173 rows.
- The sentence and line boundaries (., !, ?, line breaks) already end a clause in `requestLines`, so the chain classifier does not repeat them (port: kept, not a defect).
- A -요 ending that the list still does not read keeps the search going and errs to the pointer (port: kept, the safe direction; CRW-1166 remaining ambiguity). The morpheme dictionary and the vowel rule `politeYo` were not reintroduced: the vowel rule read 가요 and 대중가요 as verbs (CRW-1166 round 5).
- Not added: a same-clause check for a causative request before a finite -요 verb (the cost-benefit step of CRW-1173). The -고 chain already reads a causative on any later verb of the chain, and a finite verb ends it, so the check would only decide a clause the chain has settled; no row of the table needs it, and a morpheme dictionary was excluded (port: kept, a decision, not a defect).
