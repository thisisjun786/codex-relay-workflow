# CRW-1115 — the SubagentStop evidence gate looked only at the parent's native cwd

Source: CXC v0.2.40 (commit 3c1459ac) `plugins/codexclaw/components/pabcd-state/src/subagent-evidence.ts:449` and `:489` (the receipt is judged under the payload cwd's evidence directory only) and `plugins/codexclaw/components/subagent-config/src/spawn-attach-hook.ts:972-987` (the guard the child's packet gets). The Go side is `internal/pabcd/hook/subagentstop.go` (the gate), `internal/pabcd/evidence/assignment.go` (the assignment record and its checks), `internal/pabcd/evidence/lock.go`, `internal/role/spawn/guard.go` (`EvidenceAssignmentBlock`, the packet lines) and `internal/role/spawn/hook.go` / `hook_route.go` (the injection and the record). Found by the 10-10 combined review, B1-01.

- A subagent's SubagentStop payload carries its parent's native cwd, and the oracle accepts a receipt only under that cwd's `.crw/evidence`. A bounded worker that its parent assigned a separate managed worktree (dispatch-surfaces: the packet requires that path as every command's workdir) records its receipt in that worktree and is blocked at attempt 1, while identical bytes in the parent's tree pass; a packet whose scope allows no evidence write at all can only spend its three retries and leave an unresolved verdict (subagent-evidence.ts:449, :489); port: fixed. The parent's packet now declares the contract on its own lines, `CRW-WORKTREE: <absolute path>` and, for a packet that allows no evidence write, `CRW-EVIDENCE: none`. The spawn hook (the parent's own tool call, the only trusted point) records an evidence assignment for the parent's exact session under `.crw/evidence-assignments/<session>-<digest>/<id>.json`, once the spawn is allowed, and injects `[CRW-EVIDENCE-ASSIGNMENT:<id>]` after the guard with the approved receipt directory, or with the scope-conflict line. An ambiguous request (two trees, a relative or missing tree, another evidence value) is refused with a deny envelope rather than guessed. The gate accepts a receipt of a registered tree assignment only when the tree is still the registered directory (real path, device and inode; a link swapped in or a recreated directory is refused), its `.crw` and `.crw/evidence` are real directories, the receipt passes the native checks inside that root, it is not older than the dispatch, and the tree's HEAD at dispatch is still an ancestor of its HEAD (an unrelated history is foreign). The contract of a child is found from the child itself, never from the order in which receipts arrive: the packet the spawn hook injected holds `[CRW-EVIDENCE-ASSIGNMENT:<id>]`, and the SubagentStop payload names that child's own transcript (`agent_transcript_path`), a Codex rollout whose first `UserMessage` item of the child's own thread (the rollout's `session_meta` id) is that packet, so the id in it is the assignment this very actor was dispatched with. A marker anywhere else in the transcript is no contract of the child: a tool's output, the child's own words, a packet it sent to an agent it spawned, a later input and the items of a forked parent history are other lines or other threads, and the harness writes each line as one JSON value, so no output forges one. The transcript is opened without blocking and must be a regular file, so a FIFO or a device at the path never holds the gate. The id a child cites on a line `EVIDENCE_ASSIGNMENT: <id>` stands in only where the transcript shows no packet, and an actor that already claimed an assignment keeps it. A child that has a contract is judged by it alone: a receipt in the parent's native tree, old or its own, is no substitute for the assigned tree and no way around the scope conflict; a contract its packet (or citation) names whose record cannot be read (removed, damaged, of another session, an unreadable directory) refuses the receipt rather than falling back on the native root; and an actor whose packet did not hold the id cannot claim it, whoever submits first. Only a child with no contract keeps the native root. Each dispatch has its own id, so a finished dispatch of the same tree is never a candidate for a later or a concurrent one, and the receipt must not predate its own dispatch, compared at the precision the dispatch time was recorded with (a receipt of an earlier dispatch written in the same second is refused). The first actor whose receipt passes claims the assignment; another actor's receipt is refused. A child never names a root itself. Residual: where the harness gives no transcript, or one that shows no packet, the cited id is the only link, so an actor that learns another dispatch's id (the record's file name, readable in the parent's state directory) could claim it first; a hard actor binding at spawn needs a spawn-result or SubagentStart hook declaration, which this lane may not add (hook trust identity). A no-write packet ends with `EVIDENCE_SCOPE_CONFLICT: <id>`: the child is released at once with a resolvable unverified verdict (no retry spent, nothing written in its tree), the assignment is marked scope-conflict, and completion stays denied until the parent records its own verification and runs `crw pabcd evidence resolve`; an unknown or borrowed id is not an exit. Without the packet lines nothing is recorded and the native cwd stays the only root. Explorers stay outside the gate and no relay or dispatch-ledger registration is made. - Three holes of the contract lookup are closed; port: fixed. (1) An actor without an agent id claims nothing, but the contract its packet names stands: its native-cwd receipt is no substitute for the assigned tree and no way around the scope conflict, and its receipt in the assigned tree is refused too (an unclaimable assignment), where it had been judged by the native root. (2) A child tied to no dispatch at all (no readable packet in its transcript, no `EVIDENCE_ASSIGNMENT:` citation, nothing claimed) is refused while an assignment of the session is still unclaimed, because it may be that assignment's child and the parent's native tree proves nothing for it; a session with no open assignment keeps the native root, and an actor that claimed one keeps it. Residual: an unclaimed assignment whose child never stopped (an explorer is not gated) holds later transcript-less stops of that session; the gate always receives the transcript in the harness, so only a missing or unreadable one is affected, and the block ends in a resolvable verdict. (3) The spawn hook no longer treats any occurrence of the assignment marker in the packet as proof that it already registered it: only the block right after the guard (the place the hook writes it) that names an open record of this very request (the mode asked for, and for a tree the same real directory) counts as a second pass over the hook's own output, and a block at that place that names anything else is refused. A placeholder, a log or another dispatch's quoted block in the parent's text registers nothing and suppresses nothing, and the fresh block comes first, so the gate reads the child's own contract.
