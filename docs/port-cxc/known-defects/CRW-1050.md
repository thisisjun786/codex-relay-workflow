# CRW-1050 — improve collect's SQLite inputs keep the identity comparison; the draft readers read the opened descriptor

Source: Linear CRW-1050 (the CRW-990 hand-over). There is no CXC v0.2.40 oracle: improve collect and the audit draft readers are Go-only
features of the port. The Go files are internal/manage/improve_collect_identity.go (the decision, in the comment at its head),
internal/manage/audit_drafts.go (`auditDraftReadFile`, `auditDraftLoad`), internal/manage/audit_list.go and
internal/relay/store/location.go (`OpenInPlace`, unchanged). The red output is /state/crw/crw-lane-improve/evidence/red-1050.log.

- Decision: `store.OpenInPlace` does not get a variant that takes an opened descriptor; the before and after identity comparison is the
  protection for the relay and DAG SQLite inputs. SQLite opens a database by name: a descriptor can only be given to it as
  /proc/self/fd/N, which SQLite resolves back to a name at open (TestImproveSqliteOpensADescriptorPathByItsName), which exists only on
  Linux while these tools also build for darwin, and which would change an API the relay's own readers share, for a narrower window
  only. port: kept (decision recorded).
- Residual of that decision: a store file moved away and moved back inside one read keeps its inode at the name, so the comparison
  does not catch it. It needs a writer with access to the store's directory, and the stores are the operator's own. port: kept.
- The draft readers (`auditDraftLoad` for the drafts command, mark and propose, and the list command's single read) read the bytes
  from the opened descriptor and compare the file's identity after the read, so a draft replaced, swapped or removed during the read
  is refused instead of being taken for an absent or an unchanged draft (TestAuditDraftLoadRefusesADraftSwappedDuringTheRead,
  TestAuditDraftLoadRefusesADraftRemovedDuringTheRead, TestAuditListDraftsReadsEachDraftOnceUnderTheIdentityCheck,
  TestImproveProposeLeavesADraftSwappedDuringTheReadAlone, TestImproveDagStoreReplacedRightAfterItsReadIsRefused). port: fixed.
