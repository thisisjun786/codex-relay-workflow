# CRW-1182 — the account-home content snapshot follows links below the root and records a dangling root link

Source: the CRW-1176 follow-ups d2 and d3 (`lane-account-home-snapshot` 1ab6cd6e3); there is no CXC oracle for this helper, which is a test-support snapshot of the account homes. The Go file is `internal/testsupport/homes.go` (`Contents`, `walkHomeDir`, `snapshotWalk`, the budget constants); the cases are in `internal/testsupport/homes_links_test.go`, and the existing `AccountHomes` tests (`homes_test.go`) keep their expectations. Test-only helper: no production code reads it.

- A directory link below a watched directory was recorded as a link and not walked, so an in-place edit of a fixture behind it was not seen (CRW-1176 d2); port: fixed (a link is followed: a directory is walked under the link's label, a file is read through it, and a link that leaves the watched root is walked too, since the watch exists to see the fixture a link reaches. The link keeps its own line with its target. Pinned by TestContentsFollowsALinkToADirectoryUnderTheRoot, TestContentsReadsALinkedFileThroughTheLink and TestContentsWalksALinkThatLeavesTheRoot).
- A dangling root link was read as absent, so a change of its target was not seen (CRW-1176 d3); port: fixed (the root is judged with its link metadata first: a dangling link is recorded as `<label> <mode> -> <target> (dangling)` and a change of the target is a change of the snapshot. Pinned by TestContentsRecordsADanglingRootLinkWithItsTarget).
- A cycle ends the walk at its link and is marked `(cycle)`; a second link to a directory already walked is marked `(alias of <first link>)` and is not walked again. Cycles are judged by the real directories above the link (ancestry), not by a global visited set, so a plain alias is not mistaken for a cycle. Pinned by TestContentsMarksACycleAndTerminates and TestContentsWalksACommonDirectoryOnceAndMarksTheAlias.
- The walk limits are 32 nested directories, 4096 entries and 64 MiB of regular-file content. A walk past one is an error that Verify reports, so an incomplete snapshot is never taken as a pass; an unreadable entry keeps its line and its error as before. Pinned by TestContentsErrorsPastTheDepthLimit and TestContentsErrorsPastTheEntryBudget.
- Kept: HOME contributes its top-level names only, and a link at HOME's top level is a name, not walked. The retrust fixture rewrites HOME/codex on purpose, and a recursion into HOME would read that rewrite as a stray write (port: kept, the exception the existing retrust tests rely on). Pinned by TestContentsKeepsHomeToItsTopLevelNames.
