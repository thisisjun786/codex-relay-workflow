# CRW-1158 — bounded advisory ingress, binding and context

Source: CXC v0.2.40 `recall/src/cli.ts:395`, `cxc-ops/src/cli.ts:19-25`,
`cxc-ops/src/map-affordance.ts:158-169,306-320`, `pabcd-state/src/hook.ts:591-593`
and `scripts/hook-observation.mjs:17-18,49`.

- Recall and affordance read stdin without a cap. port: fixed. Both reuse
  `harness.ReadInput`: at most 4 MiB+1 physical bytes, failed input dropped before
  decoding, handlers, markers or observations. They release silently, never deny.
  Successful small input keeps BOM, Node UTF-8 and JSON semantics; cancellation
  still returns 130 and late reads have no effects. Background ingress is unchanged.
- SessionStart interpolated any session ID twice. port: fixed. Accept ASCII
  alphanumeric tokens with subsequent hyphens/underscores, at most 128 bytes,
  covering native UUIDs and existing recorder/session keys. Reject an invalid
  identity intact; do not truncate or sanitize into another identity.
- Affordance context was unlimited. port: fixed. All affordance envelopes use
  the shared 32,000 UTF-16 builder. Required binding and loop/gate pointers take
  priority over optional descriptions; small context keeps its original order.
  This affordance handler has no snapshot producer. The section builder's test
  covers required snapshot text as well as identity/gate text.
- A cut could split an astral character. port: fixed. Back off one UTF-16 unit,
  keeping the original limit and `[truncated]` marker. Other oracle hash cases
  remain unchanged; the split case is now tested against the corrected behavior.
- Explicit empty CODEX_HOME wrote observation files relative to cwd. port: fixed.
  Use the same HOME/.codex fallback as unset CODEX_HOME. Rooted relative-path
  containment accepts `/` and rejects siblings and escaped paths.

Counting-reader tests cover 16 MiB valid padded JSON, the cap, cap+1 and a
multibyte boundary, partial EIO and marker/handler exclusion. The existing
invalid-UTF-8 marker hashes remain pinned; invalid binding text is intentionally
omitted. Required-section tests and empty/unset/explicit-home tests are synthetic.
Recorded oracle corpus bytes are preserved; changed runtime expectations belong
in the existing owner's replay notes if a corpus case reaches the difference.
