# CRW-1270 — the plan summary discharges a verdict obligation by the order the writers make the record in, and by the document spelled as the target

Source: the follow-up of CRW-1216 found by its verification (head 44980832). It is the port's own addition: CXC v0.2.40 (commit 3c1459ac) has no plan summary, and `supervision.discharge_of` reads a confirmed `sync_outbox` row whose target is compared as text, so there is no oracle line for the comparison below. The Go files are internal/relay/delivery/sync.go (`PlanSummaryCarriesVerdict`), internal/relay/supervisor/obligation.go (`Reportable`), proposal.go (`ReportableCurrent`) and selection.go (`Selection`), and docs/relay/dag-outbox.md. No Go code is changed; the test is internal/relay/dagsched/outbox_discharge_test.go.

- `PlanSummaryCarriesVerdict` compares `dag_summary_outbox.document` with `sync_targets.target_ref` as two strings, and the documents did not say that the two spellings must be the same; port: kept, documented (docs/relay/dag-outbox.md states the comparison: byte for byte, neither side normalised, as the readers compare a `sync_outbox` row's `target_ref` with the target; a document named by its URL does not discharge a verdict whose target is recorded by its id, and the failure is the safe one: the verdict stays standing until a confirmed record of the target's own spelling discharges it; reporting is a separate decision (`Selection` returns `standing` with `report` false once a report was made under the obligation) and a report does not discharge it). Normalising was not chosen: the target and the document are opaque text (`dag-outbox.md`, "A stream is a plan and a document"), and a rule that resolves a URL to an id would be a new reading of a Linear document name that no contract states. Pinned by the case "document spelled otherwise than the target" of TestPlanSummaryDischargesTheVerdictThroughTheRecordingWriters.
- The discharge tests of CRW-1216 wrote the verdict row and the summary row by hand and fixed their instants, so the order `created_at >= decided_at` between the delivery clock and `Scheduler.Now` was never run through the writers; port: kept, pinned (TestPlanSummaryDischargesTheVerdictThroughTheRecordingWriters runs `Ack.RecordVerdict` (delivery clock injected, `VerdictSync` wired as the command wires it) -> `EnqueueSummary` (scheduler clock injected) -> `ClaimSummary` -> `CompleteSummary` -> `Reportable`, `ReportableCurrent` and `Selection`, which agree at every step: the verdict stands until the entry is confirmed, and no `sync_outbox` row is made. An entry stamped one second after, or at the instant of, the verdict discharges it; one stamped before it does not).
- The Source line of known-defects/CRW-1216.md named `ownedByPlanSummary`, a function that does not exist; corrected there to `planOfRelationship` and `PlanSummaryCarriesVerdict` (the `Source:` paragraph only, no defect line of that file is edited).
