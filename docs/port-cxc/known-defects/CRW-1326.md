# CRW-1326 — issue bodies named a build model and carried a done condition whose matches the edit regions did not list

Source: the 10-13 field trial (CRW-1315 items 4, 18, 35 and 44), not the CXC oracle (CXC v0.2.40, commit 3c1459ac): the oracle has no issue-writing skill of this shape. The skill side is `plugins/crw/skills/crw-add-issue/SKILL.md` and `plugins/crw/skills/crw-plan/SKILL.md`; no code changed.

- An issue body said which model builds it (CRW-1294: "Sonnet builds") while the role policy decided another, so the body was a second source of the model; port: fixed (both skills say that an issue body names no model and no effort, that the role policy, `crw role helper` read with `crw flow roles`, alone decides them, and that the child pair line names a pair family of that policy; crw-plan's issue item no longer spells the families out, which stay in the routing table of `crw-plan/references/integrations.md` the policy uses). Pinned by `TestIssueBodiesNameNoModel`, which also finds no model name in either skill.
- A done condition that searched the whole tree (an `rg` at 0) matched paths the issue's edit regions did not list (CRW-1294: the GUI source and bundle, the guard tests and the records), and a done condition without the build tag ran no test (items 35 and 44); port: fixed (when a done condition searches the whole tree, the skill runs it once when the issue is written, compares the paths it matches with `## 편집 영역`, and records a difference as a warning in the report and a line in the issue for its owner to correct; the issue is still written, because a reversible step warns and records and refuses nothing, Jun 10-14). Pinned by `TestIssueBodiesNameNoModel`.
- Kept: whether the bodies of CRW-1294 and CRW-1295 are corrected before the next trial (their done-condition tags, edit regions and model wording) is the trial designer's call, Sion's, and this change edits no Linear issue.
