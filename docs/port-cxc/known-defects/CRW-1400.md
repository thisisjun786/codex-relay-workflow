# CRW-1400 — follow-up of CRW-1398 (Argon V5 P2): crw config verifier left "disabled_servers": null as it was

Source: CRW's own configuration writer and manage tool, no CXC oracle (CXC v0.2.40, commit 3c1459ac, has no `crw config verifier` section for `manage.child_check` and no `crw manage child-resume`). The Go files are `internal/crwconfig/childcheck.go` (`withChildCheckDefault`) and `internal/manage/childresume.go` (`resumeDisabledList`, unchanged); the text is `docs/runtime-install.md` ("The servers `crw manage child-resume` switches off"). No relay store schema, receipt status, refusal code, fault class or skill is added or changed.

- `crw manage child-resume` reads `"disabled_servers": null` as not set, warns, and tells the operator to run `crw config verifier` to write the default (CRW-1398.md, first bullet; `internal/manage/childresume.go`), but `withChildCheckDefault` only tested whether the key was present in the section, so a `null` value stayed and the command the warning named changed nothing; port: fixed (`withChildCheckDefault` treats a key whose value is `null` like a missing key and writes the default, the empty list, and keeps every other key of the section, the `manage` object and the file. `[]` and a named list stay as the operator's; a value that is no list (string, number, object, a list of non-names) stays too, because the reader refuses it as `disabled_servers_unset` and this writer does not repair what it does not own. A `manage` or `child_check` value that is null or no object is left as it is, unchanged from CRW-1398. `docs/runtime-install.md` says a `null` key counts as not named. Pinned by `TestConfigVerifierReplacesANullChildCheckListLikeAMissingKey` (null, null with spaces, missing key, `[]`, a named list, string, number, object, list of non-names) and `TestConfigVerifierReplacingANullChildCheckListKeepsTheOtherKeys`; `TestConfigVerifierWritesTheChildCheckDefault` and `TestConfigVerifierKeepsTheChildCheckListAFileNames` are unchanged and pass).
- Supersedes CRW-1398.md, first bullet, its sentence "`crw config verifier` ... writes `manage.child_check.disabled_servers: []` where the file does not name it": a `null` value counts as not named; now port: fixed (see the bullet above).
