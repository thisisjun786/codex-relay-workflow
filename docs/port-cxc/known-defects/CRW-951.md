# CRW-951 — pathlib touch() and mkdir() are not read as writes by the shared shell reader

Source: the port's own shell write reader, not an oracle behaviour. The defect is in `internal/pabcd/hook`
(`shellIRWriteNames` / `shellIRPyUnattributedCall` in `shellwrite_structural.go` and `shellVerbWriteMethod` in
`shellwrite_verbs.go`). The rows that hold it are `testdata/shellir/rows/20-crw-951-touch-mkdir.txt`, run by
`TestReproductionRows` through the memory write gate, the GitHub post guard and the worktree guard.

## 2026-10-09: pathlib touch() and mkdir() (re-check RC-951, approved by Jun as mgmt-approved-20261009-0651-951-851)

- `Path(root).joinpath('a').touch()` and `Path(root).joinpath('a').mkdir()` with `root` inside the protected memories root:
  the memory gate judged them `none` and consumed no grant, while python3 really creates the file and the directory; port:
  fixed (touch and mkdir are read like write_text: a receiver that is a `Path(...)` call names its destination, any other
  receiver is an unknown destination, criterion c1e).
- A literal `Path(m).touch()` and `Path(m).mkdir()` with `m` inside the memories root, and `Path("<memories>/a").touch()`:
  the same bypass; port: fixed (the destination of the `Path(...)` receiver is read by the walk exactly as the
  destination of `Path(...).write_text(...)`; a protected destination is an attempt that needs and consumes a grant).
- Bound names, parenthesised receivers, the unbound method `Path.touch(Path(m))`, a method bound to a name and called later
  and a call inside an `exec` text: port: fixed (the unknown destination of c1e).
- Counterexamples that stay `none`: `Path('/w/x').touch()` and `Path('/w/d').mkdir()` in the work tree, `Path(m).exists()`,
  `is_dir()`, `stat()`, `os.path.exists(m)`, the text `touch()` as string data, bare names `touch` and `mkdir`; port: kept.
- Scope kept narrow: only the pathlib methods touch and mkdir. `os.mkdir`, `os.makedirs`, `os.utime` and the other
  creating calls are not read by this change and are not judged as before; port: kept (no widening, open for a later issue).
