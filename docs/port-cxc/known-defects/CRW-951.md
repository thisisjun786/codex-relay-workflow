# CRW-951 — the memory gate's Python reader names only literal destinations

Source: CXC v0.2.40 commit 3c1459ac. Oracle files:
`plugins/codexclaw/components/pabcd-state/dist/shell-write-destinations.js` (`scriptWriteDestinations` :532-549, whose
three patterns read `open(...)`, `Path(...).write_text/bytes` and the JavaScript `writeFile*` family, each only when
its path is a string literal) and `plugins/codexclaw/components/pabcd-state/dist/memory-write-gate.js`
(`handleMemoryWriteGate`, which classifies a shell command by the destinations `shellWriteDestinations` returns). Go
files of the port: `internal/pabcd/hook/shellwrite_verbs.go` (`shellWriteUnnamedCommand` and the program walk beside
`shellWriteExecScan`) and `internal/pabcd/hook/memorygate.go` (`memoryGateClassify`, which runs the new check beside
CRW-741's f-string check and CRW-726's unreadable-program check).

## Defects

- The oracle `scriptWriteDestinations` names a destination only when it is a string literal, so a Python program that
  computes it - `open(Path(m), "w")`, `open(os.path.join(root, "n.md"), "w")`, `f = open; f(m, "w")`,
  `Path(root).joinpath("n.md").write_text(...)`, `(Path(root) / "n.md").write_text(...)`,
  `Path("/w/a").absolute().rename(m)`, `Path("/w/a").rename(Path(m))`, `f = shutil.copy; f("/w/a", m)`,
  `getattr(shutil, "copy")("/w/a", m)`, `__import__("shutil").copy("/w/a", m)` and
  `shutil.copy("/w/a", os.path.join(root, "n.md"))` - writes into the memories root and passes the oracle memory gate
  without a grant (source `shell-write-destinations.js:532-549`; port: fixed, security — the port adds a third
  fail-closed check to the gate's shell branch: a program that holds a write whose destination the reader cannot name
  while it can point at the protected area is a write attempt of its own, denied with the target
  `(a program the gate cannot read: a write whose destination it cannot name)`). The oracle's own answer is unchanged,
  and no corpus fixture holds a computed destination, so none is re-tagged.
- The check over-blocks a Python program that names the protected area and writes elsewhere through a computed path:
  such a program is refused even when the write it makes lands outside the memories root, because the reader cannot name
  where it lands (source `memory-write-gate.js` classifies by destination only; port: fixed, an accepted cost — the
  issue body records this over-blocking as the price of closing the bypass, and a session that holds a grant is still
  allowed).
- The check fails closed on an unquoted here-document body the outer shell rewrites (any expansion in a
  `python3 <<PY` body) when that body holds a write (source `shell-write-destinations.js:532-549`
  reads no here-document; port: fixed, an accepted cost — a rewritten body can hide the destination, a `$VAR` that
  expands to a protected path, and the reader cannot tell; a body with an expansion and no write at all is read as the
  program it is and passes, so a read-only `print("$USER")` program is not refused).
- The check also refuses an unrelated program that merely holds a path segment named memories or .codex
  (`open(os.path.join("/a/memories/b", "n.md"), "w")` is denied), because a directory with that name can be
  the protected root under some home (source `memory-write-gate.js:296-325` compares the destination against one
  root only; port: fixed, an accepted cost — the issue body names the path segment memories and .codex as
  pointing at the protected area, and an attribute literal such as `a.memories.copy` is excluded so the common
  false positive does not fire).
- The check refuses a write method taken off its receiver as a value even when the receiver is not a Path
  (`s = "memories"; f = s.replace; f("a", "b")` is denied), because a value carries no argument count to tell a
  Path's `replace` from a string's own (source `shell-write-destinations.js:532-549` names no function value at
  all; port: fixed, an accepted cost — a value that reaches a Path write must fail closed, and the program must also
  name the protected area for the refusal to fire).
