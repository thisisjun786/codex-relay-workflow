# CRW-1142 — the hook switch warning names a dangling symlink only as a doubled path

Source: none in CXC v0.2.40: the hook switch (`<CODEX_HOME>/crw/switch.json`) is CRW's own activation gate (CRW-392, see `CRW-392.md`). The Go file is `internal/hookswitch/hookswitch.go` (`readState`), the test is `TestDanglingLinkProblemNamesPathOnceAndTarget` in `internal/hookswitch/hookswitch_test.go`. Found by the isolated real-use trial r1 (S3-F3): with `switch.json` a symlink to a target that does not exist, `switch-warning.json` carried `<path>: open <path>: no such file or directory`.

- The warning for a dangling switch link wrapped the open error, which already names the path, in the path again, and did not say the file is a symlink or where it points; port: fixed (the problem names the switch file once and says `switch file <path> is a symlink to a target that does not exist (<target>)` when `Lstat` shows a symlink whose target `Readlink` returns; any other open error is reported as the open error, with the path once. The verdict does not change: the switch reads as on, the legs run as `crw`, the warning is still written. Red on 6a5851f4f.)
