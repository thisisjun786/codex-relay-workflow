# Todo 44 phase A: group g4's recorded Python answers

Group g4 converted the Go tests of the relay's hook, store, service, registry, linkage,
mergeturn, reception, selection, inbox, capacity and argparse packages, `internal/testsupport`
(`ownership_test.go`), `internal/bridge/...`, `internal/runtime/...` and `internal/pluginwiring`
so that none of them runs the Python implementation by default. Every answer the Python
reference implementation gave a comparison is read from a recording under the package's
`testdata/python-oracle/` through `internal/testsupport/pyoracle` (unchanged): unset
`CRW_PYTHON_ORACLE` replays, `record` runs the live Python and writes, `check` runs it and
compares. The Go side of every test still runs live.

Refactor wave R2 has since replaced every one of these recordings, and the older frozen Python
outputs of the same packages, with goldens and fixtures: see
[the last section](#refactor-wave-r2-goldens-and-fixtures). The phase-A account below is kept as
the record of how each answer was taken; the helpers and recordings it names are gone.

Dispositions:

- **Converted**: an output comparison for fixed input. Python's answer is recorded; the capture
  is the test's former live-Python code.
- **Deleted**: a cross-runtime interop test or half, where a Python process and a Go process
  share a store, lock, socket, fence or file and the test depends on Python's side effects or
  timing. Reason, for every deletion below unless another is given: rollback to Python closed at
  todo 43 (`rollback_allowed=0`); the Python runtime leaves in todo 44. A Go-only half that still
  means something is kept.
- **Replaced**: a Python-side oracle swapped for a committed Go-owned one.

The drivers under `internal/*/testdata/*.py` stay for phase C: `record` and `check` still run them.
