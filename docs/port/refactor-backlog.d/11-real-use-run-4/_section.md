- [CRW-274][PR body, "Out of scope"; docs/relay/dag-scheduler.md "Accepting a result"] A parent cannot refresh a branch whose base moved after `dag-accept`. The acceptance pins the head the forge showed (`Accept`, accept.go), a moved head reads `stale_head` at `dag-merge-judge` and `dag-merge-request` and leaves the node `blocked:stale_head`, and the same output is refused `merge_candidate_moved` at the new head (`sameForgeReading`), so the candidate goes back to its child for a new generation, which is the cost CRW-274's refresh rule removes for a base that moves before the acceptance.
